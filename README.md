# СудЭП — демонстрация сайта

Статический показ: https://mikhalevaleksei.github.io/sudep-preview/

Публичные страницы и интерфейс владельца сайта. Отправка форм и платежи отключены. Исходники Django хранятся отдельно в приватном репозитории.

Кнопка «Личный кабинет» открывает интерфейс владельца без логина и пароля.
Это статическая копия с пустыми рабочими списками; сохранение, загрузка и платежи недоступны.
Реальные учетные записи и анкеты в этот репозиторий не включены.
